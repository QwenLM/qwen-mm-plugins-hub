1980 年代的纽约，孤独的狗从电视购物里订购了一台「Amica 2000」伴侣机器人。机器人醒来后，他们一起滑旱冰、划船、吃热狗、去海滩，度过了整个夏天。直到海水让机器人锈死在关闭的沙滩上，一段友谊被迫按下暂停键。四季流转，狗与机器人各自经历梦境与离别：狗遇见了鸭子与滑雪旅伴，机器人被兔子一家、小鸟一家短暂陪伴，最终被浣熊从废铁堆里重新组装。当他们再次在人海中相遇，只隔着一扇圆窗、一条街，用一支熟悉的歌彼此致意——全片没有一句台词，却把友谊、孤独、思念与「如何好好告别」讲得温柔又准确。
